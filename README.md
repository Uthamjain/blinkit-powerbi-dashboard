# Blinkit Sales Dashboard (Power BI)

## 📊 Overview
This repository contains a Power BI dashboard analyzing Blinkit’s sales performance using an Excel dataset.  
It highlights total sales, item types, outlet tiers, and customer ratings to uncover retail insights.

## 🔑 Key Insights
- **Total Sales:** $1.20M  
- **Items Sold:** 8,523  
- **Average Rating:** 3.9  
- **Average Sales per Item:** $141  
- **Top Categories:** Fruits, Snacks, Household, Frozen Foods, Dairy  
- **Outlet Analysis:** Tier 3 outlets lead with $472K; Supermarket Type1 dominates with $787K.
